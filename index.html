Since Our Last Meetup (May 14)

  • Claude Opus 4.8 — new default model; /effort xhigh for harder tasks; Fast Mode ~2.5× speed at the new lower price (May 28)
  • Claude Fable 5 — first Mythos-class model, a tier above Opus; 1M context by default — try /model claude-fable-5 (Jun 9)
  • Dynamic Workflows — say "ultracode" and Claude orchestrates hundreds of subagents; manage with /workflows (May 28)
  • Auto Mode on Pro — background safety checks replace most permission prompts; cycle modes with Shift+Tab (May 18)
  • /code-review — built-in PR review with effort levels; --comment posts inline GitHub comments (May 18)
Rapid fire — five things you can use tomorrow. One: Opus 4.8 is the new default model — /effort xhigh when you want it to grind, and Fast Mode is roughly 2.5x faster at a third of the old fast-mode price. Two: Fable 5 dropped two days ago — first Mythos-class model, a tier ABOVE Opus, with a million tokens of context by default. /model claude-fable-5 and it's yours. Three: Dynamic Workflows — still a research preview — put "ultracode" in your prompt and Claude writes an orchestration script that fans out tens to hundreds of subagents; /workflows to watch them run. Four: if you're on the Pro plan, Auto Mode landed for you — background safety checks instead of permission prompts; Shift+Tab cycles modes. Five: /code-review is now built in — effort levels like /code-review high, and --comment posts inline comments right on your GitHub PR. Honorable mentions if anyone asks: /cd moves a session to a new directory, --safe-mode launches with all customizations off for troubleshooting, fallback models, plugin search in /plugin, and a pile of worktree improvements — which is a nice segue to what Tim's showing tonight.
